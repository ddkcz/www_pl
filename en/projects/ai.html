2026 — Online portfolio

Design and development of an online presence — from zero to a working portfolio. Through extensive use of AI, the entire website was built by a mechanical engineer with no previous front-end experience. Stack and tools:

  • Vanilla HTML / CSS / JavaScript — no frameworks.
  • Hosting on Cloudflare Workers with automated deployment through GitHub Actions.
  • Dynamic loading of the header and footer from a shared layout file.
  • Project tag and filter system with a single source of truth in JavaScript.
  • Dark and light themes with the preference persisted in localStorage.

2025 — Automated Google Sheet for furniture estimates

Drawing on experience from previous estimating projects, I created a custom JavaScript application. It could generate a complete bill of materials directly from a 3D model — around 2,000 items for an entire apartment — within seconds. It saved a substantial amount of time when ordering materials and made customer estimates faster and more accurate. This is a practical example of AI application.

2021–2025 — Scripts for PLM workflows

My first Python script automated file renaming according to PLM conventions, significantly improving file-management efficiency. Over the following years I developed further scripts to automate processes in PLM systems, SolidWorks and Onshape, including automatic drawing exports from assemblies, data validation and error detection in tables.

2020 — Wake-park obstacle stability automation

I created a Python script that automated stability calculations for floating wake-park obstacles and generated reports, significantly improving the design process. A SolidWorks 3D model was analysed for buoyancy, and the designer received detailed information on where ballast should be added so the element remained stable and level in the water.

2019 — Automated Excel estimating tools

In 2019 I created several Excel tools for automated project and material estimation. They generated quotations and material schedules quickly, significantly improving sales and project-delivery processes. The calculators produced complete commercial estimates and preliminary BOMs for pump tracks. After selecting a report from a SketchUp 3D model and adding details such as surface type, installation method and location, the project could be priced immediately and a production component list prepared. I also developed this solution for FlowParks.
